# Commit+ legacy update feed

This repository preserves the Sparkle feed URL embedded in older Commit+ apps.
The application source and releases are at https://github.com/Commit-Plus/commit-plus.

`appcast.xml` mirrors https://commit-plus.github.io/commit-plus/appcast.xml.
A scheduled workflow checks every 30 minutes; it can also be run manually.
Keep this Pages site available for older installations.
